🚀 Quick Start

Make your first API call in 30 seconds. No registration needed for free endpoints.

1. Try a free endpoint (no auth needed):

curl "https://goldbean-api.xyz/weather-now?city=London"

2. Register for 20 free credits:

curl -X POST https://goldbean-api.xyz/paid/user/register \ -H "Content-Type: application/json" \ -d '{"email":"you@example.com"}'

3. Call a Baidu AI endpoint:

curl "https://goldbean-api.xyz/paid/baidu-ocr?url=https://example.com/doc.jpg" \ -H "x-user-id: GB_YOUR_API_KEY"

🤖 MCP Integration (Cursor / Claude / Cline)

GoldBean is an MCP-native server. Add it to your AI coding assistant in seconds:

Option 1: URL-based (recommended for hosted server)

{ "mcpServers": { "goldbean": { "url": "https://goldbean-api.xyz/sse" } } }

Option 2: npx (local process)

{ "mcpServers": { "goldbean": { "command": "npx", "args": ["goldbean-mcp"] } } }

Config file locations:
• Cursor: Settings → MCP → Add new MCP Server
• Claude Desktop: ~/Library/Application Support/Claude/claude_desktop_config.json (macOS) or %APPDATA%\Claude\claude_desktop_config.json (Windows)
